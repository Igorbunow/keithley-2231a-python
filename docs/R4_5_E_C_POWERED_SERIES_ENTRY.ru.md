# R4.5-E-C: ограниченный нагрузочный STEP UP/UP/DOWN/DOWN

## Статус

**SOFTWARE QUALIFIED (при успешном полном regression на целевом компьютере)**; **HARDWARE NOT_RUN**. Ни одно симулированное измерение или цифровая уставка не заменяет результаты реальных приборов. CV и CC имеют отдельные operator gate и выполняются в разных запусках. Нагрузочные H09/H10 и комбинированные соединения не являются предметом этого этапа.

## Цель

Выполнить не серию пустых OFF-only точек, а пять физических измерений с Keithley 2231A-30-3 (CH1), KEL103 и DMM7510 при единственном включении CH1, с фиксированным маршрутом:

| Точка | Команда | CV, V | CC, A |
|---|---|---:|---:|
| 0 | исходное состояние | 3.300 | 0.100 |
| 1 | UP | 3.310 | 0.105 |
| 2 | UP | 3.320 | 0.110 |
| 3 | DOWN | 3.310 | 0.105 |
| 4 | DOWN | 3.300 | 0.100 |

Нагрузки: CV — KEL103 CR40 Ω, ограничение 0.150 A; CC — KEL103 CR11 Ω, ограничение 0.100 A. Во всех случаях CH1 задан 3.30 V с max cap 3.50 V, 0.150 A и 0.60 W. CH2/CH3 выключены, клеммы пусты; режим Independent, ни DUT, ни перемычек, ни внешних источников. DMM7510 FRONT DCV включён **параллельно** выводам CH1 с соблюдением полярности и допустимых диапазонов. Проверить реальную физическую схему вручную до запуска.

## Защищённый API

`powered_step_qualification(..., sequence=('up','up','down','down'))` — **только** в специальном аппаратном квалификационном контексте, только CH1, CV/voltage или CC/current, с единственным включением CH1 и 4 указанными операциями. Прежний контекст без аргумента `sequence` сохраняет **строго один** STEP. Обычный STEP API по-прежнему OFF-only. Настройка STEP выполняется один раз **до включения** выхода. Команды и режимы проверяются production-драйвером и аппаратным адаптером, без альтернативного SCPI-исполнителя.

Допуск для 4 шагов не является общим permission для любых последовательностей, не разрешает прямые диагностические изменения, повторные включения, автоматические ретраи, запуск второй модальности, использование CH2/CH3, Series/Parallel или расширение мощности.

## Измерения и критерии

- Пять независимых последовательных снимков Keithley U/I/P, KEL103 U/I/P и DMM7510 DCV, каждый со своими монотонными временными метками; показания не являются синхронными.
- Номинальные цифровые уставки каждого шага: точное совпадение с фиксированной последовательностью и проверка регистра STEP.
- Каждая CV-ступень: подписанное изменение DMM от +3 до +30 мВ; каждая CC-ступень: изменение тока KEL103 от +2 до +20 мА и DMM от +10 до +150 мВ с учётом направления. Отрицательная ступень оценивается с инвертированным знаком, а не как положительный абсолютный результат.
- Стабильность исходной точки: возврат DMM не хуже 6 мВ (CV) либо 35 мВ (CC), возврат KEL103 тока в CC не хуже 2 мА. Это квалификационные допуски, **не** паспортные метрологические гарантии.
- Для каждого снимка проверяются: KEL INPUT ON/CR, соответствие CR, PSU CH1 ON только, CH2/CH3 OFF, CV/CC без UNKNOWN, абсолютная точка, пределы U/I/P, согласованность показаний всех приборов и `MEAS:POW?`.
- Нет испытания динамики на миллисекундных шкалах: после каждого STEP SCPI-обмен до внешнего измерения занимает заметное время. Синхронизация/триггеры пока не подтверждены.

## Fail-closed

Отклонение по любому шагу/прибору, ошибка SCPI, потеря связи или ошибочный операторский ответ **прерывают всю последовательность**, без новых STEP, повторов и переключения режима. При достоверном UART runner отключает источник и проверяет все каналы OFF; KEL103 INPUT выключается и проверяется **по собственной** связи. При неопределённой связи с Keithley дальнейший SCPI запрещён; требуется ручное физическое отключение и проверка. На завершении обязателен отдельный физический FINAL gate. DMM7510 после выполнения может остаться в настроенном DCV, KEL103 — в CR, но INPUT OFF: настройки внешних приборов всегда проверяются заново, а не наследуются.

## Применение

Только после применения инкремента, полного `unittest discover` без ошибок, `compileall`, контрольного staged SHA и отдельного коммита:

```bash
python3 tools/r4_5_powered_series_qualify.py --config config/bench.local.toml --mode cv
```

Если схемы, кабели, полярность, OFF и независимый операторский допуск подтверждены — отдельно один powered запуск:

```bash
python3 tools/r4_5_powered_series_qualify.py --config config/bench.local.toml --mode cv --execute
```

**Не запускать CC автоматически после CV.** Полученные оригинальные `events.jsonl` и терминал должны быть независимо проверены до выдачи `HW REVIEWED PASS` для этой серии. Результаты серий не закрывают автоматически аналоговые диапазоны H09/H10, полный SCPI API и ВАХ DUT.
