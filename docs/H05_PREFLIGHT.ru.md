# H05 — предварительная карточка

Состояние: **PASS; HW OBSERVED для ограниченного профиля H05**, 2026-10-26.
[Текущий протокол и полный журнал](hardware_reports/2026-10-26T190417.647970Z_H05_qualification.md).
На Keithley 2231A-30-3 (`*IDN?` firmware `1.04-1.04`) получены все шесть фронтов в
порядке CH1→CH2→CH3→CH3→CH2→CH1; измеренные интервалы начала фронтов:
2,551 / 2,491 / 4,200 / 1,189 / 1,140 с при минимуме 0,950 с. KEL103 V3.30,
CR 22 Ω: 0,9976 В / 0,0452 А / 0,0450 Вт. Чтения PSU: CH1 1,00085 В / 0,0439739 А;
CH2 0,993794 В / 0 А; CH3 0,998563 В / 0,000290878 А. Все запросы `SYST:ERR?`
вернули `0, "No error"`; конечные CH1–CH3 и INPUT KEL103 — OFF, подтверждено оператором.

Два первых прогона остановлены на дефектах анализа/счётчика захватов; следующая
версия прошла, но обнаружилось повреждение чисел в отчёте при редактировании serial.
Редактирование исправлено, текущий протокол — повтор с сохранением чисел. Offline:
93 теста PASS. Метод измерения: начало фронта — 10% при включении и 90% при выключении,
подтверждение противоположного уровня; сырые пересечения 0,5 В CH2 сохранены отдельно.
Это не проверка гальванической изоляции каналов.

## Подключение

- Keithley работает в Independent; CH1−, CH2− и CH3− сведены в общую точку возврата.
- Земляные зажимы осциллографа CH1–CH3 подключены только к этой общей точке.
- Наконечник каждого щупа ×10 подключён к плюсу одноимённого канала. CH4 не используется.
- KEL103 подключён только поперёк CH1, режим CR, 22 Ω. CH2 и CH3 разомкнуты.
- До отдельного powered-подтверждения выходы Keithley и INPUT KEL103 должны быть OFF.

**Важно:** TDS 3064B имеет общие заземлённые корпуса BNC. Подтверждённая схема
объединяет отрицательные клеммы выходов и связывает их с защитной землёй осциллографа.
Во время H05 гальваническая изоляция каналов не проверяется. См. [руководство
TDS3000B](https://download.tek.com/manual/071095704.pdf).

## Защитные проверки R3.5.15 (перед повторной аппаратной квалификацией)

- Независимая проверка результатов CH1: KEL103 U/I/P против Keithley U/I/P,
  KEL103 P против U×I, проверка CR22. При расхождении >60 мВ, >30 мА,
  >25 мВт или отклонении I от U/22 Ω более 20 мА — `ABORTED`.
- После `INPUT OFF` KEL103 требуется достоверное повторное чтение `OFF`;
  перед итоговым `PASS` читается ещё раз. Сохранение `ON` не допускает PASS.
- Все отсчёты осциллограмм должны быть конечными, времена возрастающими;
  при фиксированных 1 В: минимум в пределах −0,20…+0,20 В, максимум
  0,80…1,20 В. Относительный 10/90% фронт без полного уровня не принимается.
- Ошибка открытия осциллографа или записи события ошибки не должна обходить
  независимые попытки отключения источника и нагрузки.

Это *дополнения* к проверенному H05, а не новая схема или новые уставки.
До проверки offline-тестов обновлённый powered H05 не запускать.

## Один powered-проход

Runner прочитает и проверит x10 probe factor, настроит один захват всех трёх каналов
(Sample, 10 kpoints, 2 s/div, CH1 rising trigger 0.5 V), зафиксирует профиль
`power_only` с V/I уставками и пределами 1.00 V / 0.100 A, затем выполнит:

1. Включение CH1 → CH2 → CH3, задержка перед CH2 и CH3 — по 1 s.
2. Чтение статусов/измерений PSU и KEL103 при включённых каналах.
3. Выключение CH3 → CH2 → CH1 с теми же минимумами задержки.
4. Проверка всех OFF, пустой очереди SCPI ошибок, сохранение сырых ISF и CSV.

Ожидаемый максимум профиля — 0.10 W на канал и 0.30 W суммарно; на CH1 через
22 Ω ожидаются около 45 mA. Переходы должны идти в указанном порядке. Начало фронта
определяется по пересечению 10% полного размаха при включении и 90% при выключении;
фронт принимается, только если сигнал затем достигает противоположного уровня. Это
подавляет дрожание CH2 около 0,5 В при медленном спаде ненагруженного выхода. Сырые
пересечения 0,5 В сохраняются отдельно как диагностика. Каждая запрограммированная
задержка 1 s проверяется по общей оси времени осциллограммы с допуском 50 ms. Все
отвергнутые API вызовы должны блокироваться до передачи SCPI.

Подтверждение, которое разрешит ровно этот powered-проход:

```text
CONFIRM H05 POWERED INDEPENDENT ALL_OFF LOAD=KEL103_USB=/dev/ttyACM0_115200 CH1=CR22 CH2=OPEN CH3=OPEN SCOPE=COMMON_NEGATIVE_X10 PSU=1.00V_0.100A DELAY=1S RECALL=OFF
```

CLI по умолчанию не открывает приборы. При запуске указать текущий порт Keithley
(последний известный — `/dev/ttyUSB3`) и явно выбрать KEL103 USB:

```sh
python3 tools/hw_qualify.py run H05 --execute --config config/bench.local.toml
```

Перед открытием портов CLI запросит этот точный powered-токен. После завершения
runner запросит отдельное подтверждение физического OFF. При таймауте связи автоматического
переподключения нет; проверьте OFF сетевыми выключателями и на дисплеях.
