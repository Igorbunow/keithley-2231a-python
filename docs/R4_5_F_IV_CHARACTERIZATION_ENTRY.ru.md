# R4.5-F — план перехода от STEP к измеряемой ВАХ (подготовка, HW NOT_RUN)

**База:** независимые реальные пять установившихся точек R4.5-E-C CH1 CV / CR 40 Ω и CH1 CC / CR 11 Ω прошли review. Доказаны относительные изменения величин и обратимость короткой серии, но не калибровочная точность, переходная характеристика и готовность к неограниченному сканированию.

## Граница следующего этапа

Не переносить в production API возможность произвольных powered STEP. Нынешний квалификационный контекст допускает только заранее фиксированную последовательность `UP, UP, DOWN, DOWN` и отдельное разрешение на каждый CV/CC-сеанс. R4.5-F должен иметь *собственные* программные тесты, пределы числа точек, времени, энергии, абсолютной мощности, отказов приборов, переходов CV/CC и состояние OFF.

Для первого R4.5-F пилота разумна **заведомо известная резистивная нагрузка**, CH1 only / Independent, низкая мощность, KEL103 в CR (при поддержке точного фиксированного сопротивления), DMM7510 измеряет DCV параллельно нагрузке. Изменяемая уставка источника не должна выходить за разрешённые пределы и должна подтверждаться `VOLT?` после каждой операции. На каждой точке записать с отдельными метками времени:

- фактические `MEAS:VOLT?`, `MEAS:CURR?`, `MEAS:POW?` Keithley, его CV/CC status и цифровую уставку;
- независимо измеренные KEL103 U/I/P, точное подтверждение CR/INPUT state;
- `:READ?` DMM7510 с подтверждённым FRONT/DCV/range/NPLC; различать последовательную выборку и истинную синхронизацию;
- ошибки, ограничения, дисперсию при повторении выбранных точек, прямую и обратную ветви ВАХ, систематическое различие измерителей и время между SCPI-командой и началом измерения.

Не использовать DMM как силовую нагрузку. Для нелинейного DUT (диод и т. п.) сначала требуется отдельная схема, резистор ограничения тока, критерий максимальной энергии, точки измерения самого DUT, осмотр полярности и независимое разрешение на DUT. Этот этап здесь **не разрешён**.

## Fail-stop и критерии квалификации

1. DRY RUN и тесты UART/скриптов отказов **без подключения оборудования**: неверная модель/канал, неверное сопротивление, отказ DMM/KEL, отсутствие дельты, потеря UART, ошибка SCPI, неожиданный CV↔CC, смещение уставок, повтор команды при неопределённом результате, пропуск финального OFF.
2. Один операторский разрешённый и ограниченный аппаратный пилот после успешного полного regression; не запустить CC и CV автоматически в одном сеансе.
3. Истинные по-проводные команды и независимые физические измерения всех точек в оригинальном JSONL с SHA-256, точной идентификацией runner/stage и отдельным OFF-обзором.
4. **Без `HW REVIEWED PASS` по оригинальному evidence нельзя считать R4.5-F готовой экспериментальной ВАХ**. Для скоростной ВАХ понадобится отдельный способ временной синхронизации, а не только последовательные SCPI-снимки через несколько секунд.

**Текущий статус R4.5-F: PLANNED / HW NOT_RUN.** Этот документ не добавляет CLI и не разрешает силовые операции.
