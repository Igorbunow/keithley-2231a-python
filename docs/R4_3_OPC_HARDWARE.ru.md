# R4.3-C — аппаратная квалификация `*OPC?` в состоянии простоя

**Статус: HW REVIEWED PASS (ограниченный idle-only сценарий 2026-10-29).**
Результат программных тестов не заменяет проверку на
реальном Keithley 2231A-30-3. Никакого `*WAI`, `*OPC` (запись), `*TRG` или
изменения уставок этот сценарий не выполняет.

## Что подтверждается

Один `*OPC?`, принимается **только** ответ `1`, в новой сессии без профиля и
без фонового монитора. Команда может задержать ответ до завершения предыдущих
операций. Предполагается отсутствие ожидающих/длительных операций: не
использовать этот тест во время исполнения последовательностей или работы
других программ. Проверка **не** подтверждает реальную работу с очередью
операций, точность ожиданий, сохранение SESR/OPC-бита или гарантированное
время отклика. Модульные тесты не доказывают работу на железе.

## Подготовка

- Только **один** Keithley; все CH1/CH2/CH3 физически OFF.
- Клеммы пустые, нет нагрузки/DUT/перемычек; режим Independent, Recall OFF.
- Другие программы не управляют прибором. USB-путь и VID:PID — из
  приватного `config/bench.local.toml`; тайм-аут Keithley `timeout_s` >0 и <=3s.
- Стартовые BENCH и OFF и финальное OFF подтверждения обязательны.

## Запуск (только оператор, интерактивный терминал)

```bash
python3 tools/r4_3_opc_qualify.py --config config/bench.local.toml
python3 tools/r4_3_opc_qualify.py --config config/bench.local.toml --execute
```

Сохрани **терминальный лог** и созданный `reports/hardware/.../events.jsonl`.
Аппаратный прогон 2026-10-29 рассмотрен независимо:
[отчёт](hardware_reports/R4_3_OPC_review_2026-10-29.md). Для любого
нового прогона результат остаётся непроверенным до анализа новых файлов.
При неожиданном ответе
или потере связи: **не повторять запрос**, не посылать OFF по сомнительному
каналу; проверить физический OFF, остановить сценарий и сохранить evidence.

Успешный результат подтверждает только один запрос в состоянии простоя,
маски ESE/SRE и три выхода OFF до/после. `SYST:ERR?` опрашивается после
каждой валидной команды, кроме финального `SYST:LOC`, как в предыдущих стадиях.
Выходы не включаются; `SYST:LOC` и финальное OFF подтверждение оператора
не являются электрическими измерениями. Команда `*OPC?` может затрагивать
семантику стандартного регистра событий: **latch не читаем и не очищаем**.
