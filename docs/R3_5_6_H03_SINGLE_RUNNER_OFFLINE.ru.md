# R3.5.6 — H03 CH1 Single CV/CC: исполнительное ядро и offline-аудит

**Статус:** CODE COMPLETE FOR SIMULATION; NOT HW AUTHORIZED.

Добавлен `tests/hardware/single_cvcc_stage.py` с отдельной функцией
`run_single_cvcc(transport, evidence, load, point)`. Она не используется
CLI `tools/hw_qualify.py`: `run H03 --single-channel-cvcc --execute` всё ещё
отвергается ДО проверки USB и открытия портов. Без отдельного инкремента
интеграции, анализа сценария подключения и разрешения аппаратного запуска
выполнение на стенде запрещено.

## Инварианты

- Только CH1 может получать `CHAN:OUTP 1`. Команда `OUTP 1`, включение
  CH2/CH3 и произвольные SCPI-записи запрещены до передачи в драйвер.
- Для CH2/CH3 разрешены только исходные OFF-уставки и лимиты из
  `[qualification.h03_single_cvcc]`. Конфигурация проверяется повторно.
- Используются `Keithley2231A.apply_profile`, `set_channel`, `output`,
  `read_channel`, `output_states` и общий `StageAdapter` с автоматическим
  `SYST:ERR?` после SCPI операций. Raw transport bypass отсутствует.
- До любой мутации требуется реальный readback OFF для всех CH и INPUT OFF
  для KEL103; начальная ошибка не запускает автоматические записи.
- Последовательность отдельно для CV (CR 40 Ω) и CC (CR 12 Ω):
  `PSU all OFF / LOAD INPUT OFF` → установка U/I и повторный OFF →
  подтверждение физической полярности и CH2/CH3 без проводов →
  CR setup/readback при INPUT OFF → INPUT ON/readback → отдельное
  подтверждение CH1 ON → readback всех каналов → измерение U/I/P и режима →
  дисплейный gate → CH1 OFF/readback → LOAD INPUT OFF/readback → gate OFF.
- Потолок мощности 1.2 Вт, требования к CV/CC, измерениям и расхождению
  PSU/KEL103. Несовпадение режима, напряжения, тока или мощности — FAIL.
- При нарушении доверия к связи не отправлять повторов на соответствующий
  прибор. Выключать можно только по другому достоверному каналу, с
  последующим readback; иначе состояние UNKNOWN и нужен физический стоп.
- Записываются профили, точки, прочитанные измерения, подтверждения и
  конечный `query_outcome`. Это ещё не означает `HW VERIFIED`.

## Локальные программные тесты

```bash
PYTHONPATH=src:tests:tests/hardware python3 -m unittest \
  tests.offline.test_h03_single_config \
  tests.offline.test_h03_single_runner -v
```

Регрессии: CV и CC на модели; изоляция CH1; запрет включения без gate;
изначальное ON; изначально включённый INPUT; потери связи PSU и KEL103;
ошибка режима; мощность выше лимита; остановка оператором до включения;
запрет соседних `SYST:ERR?`.
