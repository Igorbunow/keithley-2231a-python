# Как участвовать в проекте

[Русский](CONTRIBUTING.ru.md) | [English](../CONTRIBUTING.md)

Приветствуются исправления, документация, эмуляторные тесты и воспроизводимые аппаратные испытания.

1. Создать ветку, установить пакет `python -m pip install -e .`, запустить `python -m unittest discover -s tests -v`.
2. Сохранять совместимость с прежними импортами `keithley2231a`; несовместимые изменения явно описывать.
3. Для новой SCPI-команды изменения настроек обеспечить проверку границ, при возможности readback и автоматический тест. Пока нет аппаратного отчёта, указывать **HW UNVERIFIED**.
4. Аппаратные испытания добавлять через `docs/hardware_reports/TEMPLATE.md` с моделью, прошивкой, коммитом, измерительным стендом, условиями и фактическими результатами. Не публиковать серийные номера и закрытые сетевые адреса.
5. Примеры при первом запуске не должны автоматически включать выходы. В режимах Series/Parallel отдельно указывать **обязательные внешние физические соединения**: SCPI не соединяет клеммы внутри прибора.
6. Поддерживать единообразие английской и русской документации; особенно внимательно переводить предупреждения и статусы проверок.
7. Не копировать документацию производителя и сторонние лицензируемые файлы без разрешения, выполнять условия лицензий зависимостей.

Проверить перед pull request: тесты, обратную совместимость, правдивый статус аппаратной проверки, двуязычные изменения, отсутствие секретов и защищённую по умолчанию работу с выходами.
