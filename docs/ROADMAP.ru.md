# Дорожная карта

[Русский](ROADMAP.ru.md) | [English](../ROADMAP.md)

**0.2.0 — текущий комплект:** оформление GitHub/MIT, документация RU/EN, профили полного паспортного диапазона и `power_only`, обратная последовательность отключения, ВАХ, координация нескольких Keithley и измерителей, таблица квалификации, программные тесты.

**0.3 — аппаратная квалификация:** на прошивке 1.04-1.04 проверить SCPI-команды без нагрузки, затем включение CH1/2/3 и измерения на эквиваленте нагрузки, CV/CC, таймеры, восстановление после сбоев, Series/Parallel (обязательно **внешние физические перемычки**) и Tracking. Собрать проверяемые отчёты.

**0.4 — универсальные измерительные сценарии:** многомерные развертки с изменением нескольких каналов, условные остановки по показаниям DMM/осциллографа, унифицированные интерфейсы подключаемых драйверов измерителей других производителей (возможно PyVISA), сохранение метаданных эксперимента и графики.

**0.5 — микроконтроллерный Ethernet-мост и синхронизация:** прозрачный UART–TCP сервер с одним клиентом, контроль доступности, понятная политика обрыва связи, внешняя аппаратная защита для автономных стендов. Отдельный интерфейс аппаратных триггеров и синхронизации часов. Проверка фактических интервалов осциллографом; не смешивать аппаратную синхронизацию с последовательной программной координацией.

**В перспективе:** расширение безопасно поддерживаемых SCPI-команд, поддержка других блоков питания, более сложные ВАХ/характеристики устройств, управление группами источников и измерительных приборов, матрица совместимости по прошивкам.

Ни один этап не получает статус `HW VERIFIED` без отчёта об испытании реального прибора. Программные тесты сохраняют статус `SIM TESTED`.
