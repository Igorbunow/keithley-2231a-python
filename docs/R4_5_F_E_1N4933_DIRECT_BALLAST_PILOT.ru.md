# R4.5-F-E — прямое измерение DMM7510 на балласте 99,86 Ом

**Статус: SOFTWARE CHECK / HW NOT_RUN / NOT_REVIEWED.**

Это **отдельный** ограниченный аппаратный runner для единственной рабочей точки
CH1=0,90 В / I_limit=0,020 А / V_limit=1,05 В. Применяется единый публичный
драйвер Keithley, общие `BenchConfig`, `equipment.DMM7510`,
`R44ScalarScope` и `ShutdownEvidence`. Других приборов runner не открывает.
Не заменяет предшествующий офлайн-план R4.5-F-E и не утверждает точность тока.

Схема при выключенных CH1/CH2/CH3: CH1+ → 99,86 Ом → анод 1N4933 → катод
(полоса) → CH1−. DMM7510 FRONT DCV HI — на сторону резистора к CH1+,
LO — на сторону анода. KEL103 физически отключён. Не использовать токовые
гнёзда DMM; не менять соединения при включённом источнике. Мощность резистора
не менее 0,25 Вт, проверить физически. Внешние источники/перемычки отсутствуют.

Перед включением runner проверяет идентификацию, independent topology,
OFF всех каналов, конфигурацию DMM, отключение таймеров и фиксированные
уставки; нулевое падение напряжения на резисторе при OFF. После отдельного
POWER-подтверждения включает CH1 **один раз**, снимает чтения Keithley и DMM,
пишет сырые значения до защитной оценки, вычисляет `U_R_DMM/99,86 Ω` и
`I_PSU-I_R`, затем отключает источник с аппаратным readback и запрашивает
ручное подтверждение OFF. Предварительные оценки ~0,230 В и ~0,335 В из
старого опыта **не являются допусками или эталонами**. Вне широкого
диагностического диапазона 0,10–0,65 В тест остановится; это не утверждение
о неисправности прибора.

Если UART-связь становится неопределённой, повторов/переподключения нет,
OFF программно не подтверждается, необходим физический контроль на панели.
Лимит времени программы 90 с **не** представляет собой независимый аппаратный
watchdog/interlock. Квалификация ограничивается одной установившейся точкой;
для признания аппаратного результата PASS нужен отдельный офлайн-аудит
оригинального JSONL после испытания.

## Применение

Сначала только программная проверка (без приборов):

```bash
python3 tools/r4_5_1n4933_ballast_qualify.py \
  --config config/bench.local.toml
PYTHONPATH=src:tests:tests/hardware python3 -m unittest discover -s tests -q
python3 -m compileall -q src tests tools experiments
```

**Только после проверки патча и отдельного физического подтверждения**
оператор может выполнить локально на стенде (не автоматизировать):

```bash
python3 tools/r4_5_1n4933_ballast_qualify.py \
  --config config/bench.local.toml --execute
```

Сохранить `terminal.log` и **оригинальный** `events.jsonl` без редактирования.
Даже если console runner выведет `PASS`, статус остаётся `HW NOT_REVIEWED`
до независимого анализа журнала.
