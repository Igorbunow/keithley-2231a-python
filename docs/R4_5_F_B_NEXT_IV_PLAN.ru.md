# R4.5-F-B — следующий этап после эталонной CR40 ВАХ (план; HW NOT_RUN)

Первичная R4.5-F-A дала пять аппаратно подтверждённых стационарных точек известной нагрузки CR40, но не является тестом нелинейного DUT. Не следует просто расширять допустимые напряжения или выдавать пилот за универсальный trace.

Следующий шаг — программное обеспечение для **экспорта и анализа приборно подтверждённых I–V точек** без нового powered-разрешения: CSV/JSON с исходными командами, timestamp U/I/P для каждого прибора, полем `sampling=SEQUENTIAL_NOT_SYNCHRONIZED`, вычислением прямого/обратного хода, квантования, невязки PSU/KEL/DMM, абсолютных и инкрементальных сопротивлений. Сырые аппаратные файлы с серийными номерами не публиковать; экспорт редактировать.

Перед новой *физической* ВАХ неизвестной либо нелинейной нагрузки отдельно согласовать её двухполюсную схему, предельный ток, внешний токоограничивающий элемент, рассеиваемую мощность, точки подключения DMM и ограничение по времени. Не ставить KEL103 и нелинейный DUT параллельно, как будто KEL измеряет ток DUT: это измеряет сумму/другую ветвь, а DMM измеряет напряжение, не ток. Нужен отдельный **токовый измерительный маршрут**, например утверждённый измерительный шунт с DMM на нём или отдельный точный амперметр; пользователь должен физически подтвердить схему и пределы.

Сначала offline UART/fault regression и независимое описание безопасного эксперимента, затем DRY RUN и отдельный операторский `--execute`. Никаких скрытых rearm/reconnect, raw SCPI и повторов. Скорость переходных процессов требует самостоятельной синхронизированной инструментальной методики; длительные SCPI snapshots её не доказывают.
