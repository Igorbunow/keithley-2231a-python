# R4.5-F-D — независимая проверка прямой ВАХ 1N4933

## Область квалификации

**INDEPENDENT EVIDENCE REVIEW PASS** для пяти установившихся точек прямой ВАХ,
измеренных 30.10.2026, при использовании только CH1, диода 1N4933,
балласта 99,86 Ом (измерен оператором при 26 °C) и DMM7510 FRONT DCV.
Область подтверждения: **FORWARD_STEADY_STATE_SCREENING_ONLY**.

Это не квалификация абсолютной точности измерения тока, не калибровка,
не измерение обратного тока/напряжения, пробоя, импульсной проводимости
или времени обратного восстановления. KEL103 не участвовал.

- Длительность подачи питания: 15,713 с; уставка ограничения CH1 — 20 мА.
- Возврат начального значения: 0,1057 мВ по диоду и 10,31 мкА по
  расчётному току.
- Keithley: 704 запросов, 157 команд записи, 430 опросов `SYST:ERR?`
  с нулевым кодом; DMM7510: 18 нулевых ответов на `:SYST:ERR?`.
- CH1 разрешён один раз, четыре изменения уставки выполнены строго по плану,
  CH2/CH3 оставались OFF, финальный OFF подтверждён обратным чтением и оператором.
- Из исходного JSONL не обнаружены SCPI-ошибки, потери UART/TCP и
  незавершённые команды. Отказ первого прогона не исчезает из истории.

**Ограничение точности:** встроенное измерение тока Keithley в этом опыте
в среднем ниже оценки через балласт на 1,067 мА (максимальное расхождение
1,097 мА). Причина не установлена; это не повод исправлять показания
программной константой. Ток по балласту вычислен из двух последовательных,
не синхронизированных измерений напряжения. Точность тока не подтверждена
независимым амперметром. Количественные выводы об абсолютной точности
здесь **запрещены**.

## Воспроизведение проверки на компьютере (без приборов)

Проверяющий модуль принимает только неизменённый JSONL, полную SHA-256
и фиксированные подтверждённые версии runner, stage, плана и стенда.
Файл исходного JSONL не модифицируется, отчёт печатается в терминал.

```bash
python3 tools/audit_r4_5_1n4933_evidence.py \
  --evidence reports/hardware/2026-10-30T153942.522961Z_R45FD_1N4933_forward_five_points/events.jsonl \
  --sha256 bdb2859180a8aaadf13a0d6e76e46111dbdb0d2b606977b2dbc016e7a87fd56b
```

Вывод `INDEPENDENT EVIDENCE REVIEW PASS` означает **офлайн-проверку
оригинальных доказательств**, а не новое физическое измерение.
Следующий аппаратный эксперимент требует отдельного утверждённого плана,
подтверждения новой схемы и разрешения оператора.

Номер коммита базовой реализации из оригинала: `9fc4db4` плюс незакоммиченные
на момент испытания staged-патчи. Хеши реально использованных исполняемых
файлов проверяются аудитором отдельно.
