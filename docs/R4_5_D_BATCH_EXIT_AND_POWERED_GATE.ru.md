# R4.5-D: пакетный выход из OFF-only STEP в измерения CV/CC

## Доказательства и область результата

Независимо рассмотрен оригинальный журнал 2026-10-30 CH1 `CURR:STEP 0.010`, SHA-256
`e047b8591258fd0f4f7bb8bcea4aa8517f10eddb8a28a57ee7dac047ef447f5a`.
Аудитор предыдущего ревью выдал `REVIEWABLE_PASS`: `0.100 → 0.110 → 0.120 → 0.110 → 0.100 A`, все выходы OFF, без ошибок SCPI. Состояние — **HW REVIEWED PASS только для цифрового OFF-only CH1/10 мА**. Ранее прошли CH1/1 мА, CH1/5 мА, CH1/10 мВ; напряженческий STEP 1 мВ прибор отклонил кодом 120.

`*IDN?`: встречаются `Main 1.04/Aux 0.01` и `Main 1.04/Aux 1.04`, включая переходы после опроса CH3. Это ранее изученная аномалия метаданных, а не доказательство замены источника или сбоя уставок. Записывать фактическую строку, не подменять её; не отключать проверку модели, режимов или ошибок. По мнению оператора, ответ Tektronix ожидается. Новое расследование версии в текущую квалификацию STEP **не входит**.

## Сокращённая аппаратная матрица

Для проверки полной цифровой токовой матрицы добавлен **один** операторски разрешаемый runner:

`python3 tools/r4_5_step_batch_qualify.py --config config/bench.local.toml --matrix current`

Без `--execute` — исключительно DRY RUN, без открытия портов. С `--execute` один сеанс с одним Independent-профилем, **девять** испытательных случаев, фиксированный порядок:

- CH1: 1/5/10 мА, начальная уставка 100 мА;
- CH2: 1/5/10 мА, начальная уставка 50 мА;
- CH3: 1/5/10 мА, начальная уставка 50 мА.

Для каждого случая проверяется ровно одна запись `CURR:STEP`, `CURR:STEP?`, `CURR:UP`, `CURR:UP`, `CURR:DOWN`, `CURR:DOWN` с числовыми `CURR?` и обязательным возвратом к исходной уставке. До/после изменения обязательно `require_outputs()`; проверяется Independent и текущий профиль. При первой ошибке **вся матрица останавливается**, без повторной попытки и пропуска; при живой связи — аварийный OFF и readback; при неизвестной связи только ручной OFF. Гарантированный останов/выключение не может быть заявлен при потерянной связи.

Есть альтернативы `--matrix voltage` (9 случаев: CH1/CH2/CH3 × 10/50/100 мВ) и `--matrix all` (18 случаев); эти режимы **не предназначены для автоматического продолжения текущей работы**. Без отдельного физического разрешения не запускать их просто ради полноты числа. Бюджет StageAdapter: максимум 25 000 SCPI-операций плюс 260 резерва для shutdown, 2700 сек суммарного машинного времени, время ручного ввода исключается. Тесты подтверждают полный `all` на UART, но никакой аналоговый выход при этом не включался.

После реального прохода запускать `tools/audit_r4_5_step_batch_evidence.py` на оригинальном JSONL с его реальным SHA-256; аудит сравнивает 9/18 случаев и физическую трассу. **Пока журнал независимо не рассмотрен — это HW NOT_REVIEWED.**

## Приоритет следующего этапа: реальный STEP под нагрузкой

**OFF-only цифровая проверка не означает EXPERIMENT READY.** Нельзя утверждать аналоговый шаг 1 мА по одному цифровому `CURR?`. Следующий обязательный интеграционный тест — **powered CV/CC**, с двумя измерительными устройствами:

- **KEL103** — управляемая электронная нагрузка; измеряет U/I/P. Настройка CR и вход INPUT OFF/ON только по его самостоятельным readback. Не подменять её одним DMM.
- **DMM7510** — независимая проверка напряжения на клеммах Keithley, в режиме DCV с правильным входом FRONT, защищённым диапазоном и обоснованной разрядностью. DMM не является электронной нагрузкой и в режиме измерения напряжения не доказывает точность тока CC.
- **Keithley 2231A** — рабочая уставка, `MEAS:VOLT/CURR/POW` и режим CV/CC. Сравнивать одновременные результаты, время установления, повторяемость, отклонения PSU U/I/P от KEL и DMM, а также энергетические/тепловые ограничения.

Порядок будущего powered-runner: отдельное физическое подтверждение подключения CH1→KEL103 и DMM7510 параллельно, CH2/3 полностью свободны; KEL INPUT OFF при любом переподключении; сначала низкоэнергетическая CV-точка, затем CC-точка; управляющие шаги STEP разрешаются **только в специальном аппаратно квалифицированном профиле**. Текущий `configure_source_step()`/`step_source()` пока законно блокирует любые STEP-мутации при ON и включение после STEP-сессии. Это нельзя обойти через `diagnostic_write` или сырой UART. Неизвестный readback, нарушение независимого измерения либо связь неопределённа => STOP с независимым управлением OFF для каждого устройства, ручной контроль состояния.

Для CV/CC будут отдельные gates, допустимые CR, токи, напряжения и обоснованные допуски на основании уже испытанных H03/H04. Требуется проверить SCPI-мощность `MEAS:POW?` и независимую мощность KEL, а не только U×I на одной точке.

### Критерий завершения

После **одной** проверенной пакетной цифровой матрицы токов больше не создавать отдельные OFF-only этапы для каждого оставшегося элемента без нового обоснования риска. Приоритет — физические CV/CC с DMM+KEL. Даже успешный batch остаётся `HW VERIFIED digital OFF`, не `EXPERIMENT READY`.
