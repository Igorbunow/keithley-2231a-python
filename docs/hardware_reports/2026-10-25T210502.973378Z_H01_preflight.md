## Operator follow-up and offline patch — 2026-10-26 MSK

Оператор сообщил после прогона: в меню ошибки **`170, Invalid command`**.
Это физическое свидетельство отклонённой команды. Последним запросом был
`OUTP:PARA?`; исходная очередь до первого прогона не читалась, поэтому строгая
причинная привязка к этому запросу требует успешного повторного прогона.

В manual 077100401, 5-16, синтаксис ветки OUTPUT дан как `PARallel`, то есть
короткая форма `PAR` или полная `PARALLEL`. Пример `Outp:para 1` противоречит
этому написанию; в другой ветке `INSTrument:COMbine:PARAllel` сокращение PARA
действительно указано. Библиотека использовала спорную форму PARA и для OUTPUT.

Минимальный патч заменяет её на полную документированную `OUTP:PARALLEL`
во всех трёх местах `device.py` (OFF, ON, query) и в H01. API не меняется.
Эмулятор больше не принимает спорную форму; существующая проверка профиля
сначала упала на старом драйвере, после исправления прошли **46/46 offline**:
`PYTHONPATH=src python3 -m unittest discover -s tests -v`, Python 3.13.5.
Физическая совместимость полного имени пока HW UNVERIFIED.
