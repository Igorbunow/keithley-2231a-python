# R4.3-B `*PSC?` hardware qualification — independent review 2026-10-29

**Decision: HW REVIEWED PASS (bounded PSC_QUERY_ONLY scope)** on one physical
Keithley 2231A-30-3, firmware `1.04-1.04`. The verdict covers exactly one
`*PSC?` query, return value `0`, and no observed change to *zero* ESER/SRER
masks, with outputs independently read as OFF before and after. It **does not**
validate the write form `*PSC`, power-on reset semantics, retained nonzero
masks, SRQ/interrupt behavior or a DUT/load measurement.

## Limits and nonblocking observations

1. A `*PSC?` result of **0** is a valid observed bit value. This test does not
   show behavior of ESER/SRER on an actual power-cycle, does not write `*PSC`,
   and does not establish a universal default or a result for value **1**.
2. The enable masks were zero both times; there was no mutation stimulus, so
   no proof of nonzero-mask preservation or of service-request operation.
3. OFF observations are sequential SCPI readbacks, not continuous interlocks,
   an independent voltmeter/current measurement, or proof of no intervening
   external control; the operator confirmed empty terminals, no jumper, and
   physical OFF before and after.
4. The last `INST:NSEL 1` write was followed by a clean `SYST:ERR?`, but **not**
   an independent final `INST:NSEL?` readback. Earlier selected-channel checks
   were valid. Final `SYST:LOC` is not error-polled by design; after-LOCAL OFF
   is an operator assertion. Do not upgrade these observations to electrical
   measurements or an independently read back final selection.
5. The initial BENCH/INITIAL approvals were entered before opening evidence,
   as shown in terminal; JSONL `pre_open_approvals` is a *retrospective marker*,
   not a timestamp of the operator's original keystrokes.
6. No KEL103, DMM7510, oscilloscope or DUT was exercised in this run. Listing
   their endpoints in `bench.local.toml` output is not measurement evidence.

**Decision:** accept R4.3-B read-only `*PSC?` as qualified in this narrow scope.
Commit the staged driver + this report. Continue risk-based R4.3 analysis;
no additional hazardous SCPI writes, power cycling, resets, save/recall or
multi-instrument orchestration are authorized by this PASS.
