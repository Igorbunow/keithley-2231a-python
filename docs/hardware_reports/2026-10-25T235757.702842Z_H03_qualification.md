## Operator review addendum — received after shutdown

After the runner had aborted and shutdown had completed, the operator supplied both
`CONFIRM H03 DISPLAY CH3 PSU=CV KEL=CR INPUT=ON` and
`CONFIRM H03 CH1=OFF CH2=OFF CH3=OFF LOAD=OFF`. The first token is a retrospective
panel observation for the powered CV point; it arrived too late to satisfy the live
gate. The second confirms final OFF. The run outcome remains **ABORTED**.

At the powered point the recorded readings were Keithley 3.99493 V / 0.100668 A /
0.402329 W and KEL103 4.0003 V / 0.0999 A / 0.3996 W. The Keithley error queue
returned `0, "No error"` throughout. CH3 status reads were `STAT:OPER:INST:ISUM3:COND?`
`8` (ON bit only) and `STAT:QUES:INST:ISUM3:COND?` `1` (CV bit); the panel
confirmation agrees with the latter. The official reference manual defines CV as bit
0 and CC as bit 1 in both channel summary registers, and ON as bit 3 in the operation
summary. Thus operation status contradicts the manual and the independent observations.
This is a physical status inconsistency, not an SCPI error-queue error. H03's
qualification rule does not accept this mismatch or infer PASS by silently substituting
the questionable register. This specific run remains ABORTED because the live display
gate was interrupted and the confirmation arrived after shutdown. No hardware commands
were sent after the final OFF confirmation.

Reference: [Keithley 2231A-30-3 Reference Manual, status model, p. 5-30](https://download.tek.com/manual/077100401_Referencemanual.pdf).
