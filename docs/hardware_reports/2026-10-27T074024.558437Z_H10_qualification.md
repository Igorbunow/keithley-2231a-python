## Disposition

H10 remains PARTIAL. The current generic independent profile does not model the
observed combined registers safely enough for a powered Parallel test: channel
selection aliases CH2, the pair's voltage limit enable is off in Parallel, and
exiting Parallel rewrites CH1/CH2 setpoints and leaves their limit enables off.
A dedicated guarded Parallel profile must account for equal pair voltage,
aggregate current, software voltage cap while hardware limit enable is absent,
CH3 isolation, and explicit profile restoration. Validate this contract offline
before authorizing any powered run. Do not infer 50/50 current sharing.
