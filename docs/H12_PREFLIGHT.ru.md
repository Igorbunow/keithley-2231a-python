# H12 — Негативные сценарии и финальное состояние

Аппаратная часть: **NOT_RUN**. Подготовлен OFF-only runner; ни один выход не
включается. Неверные ответы и отказы I/O вводятся только в эмуляторе.

## Подключение и пределы

Keithley: `/dev/ttyUSB3`, USB–TTL UART 9600 8N1. Все три выхода OFF,
Output Recall=Off. Клеммы всех каналов свободны: KEL103, DMM, осциллограф,
общая шина и перемычки физически отключены. KEL103 INPUT OFF; режим и значение
нагрузки не задаются. Сетевой выключатель Keithley должен быть доступен.

| Канал | Итоговая уставка V/I | Предел V/I |
|---|---:|---:|
| CH1 | 1.00 V / 0.100 A | 2.00 V / 0.300 A |
| CH2 | 1.50 V / 0.200 A | 3.00 V / 0.400 A |
| CH3 | 2.00 V / 0.300 A | 4.00 V / 0.500 A |

ON запрещён scope runner. Нагрузка отключена, передача мощности не предполагается;
при неожиданном ON немедленно остановиться и выключить прибор вручную.
`VOLT:LIM` ограничивает уставку и не является независимой OVP.

## Проверки

Офлайн: неверные каналы, NaN/Inf, отрицательные значения, превышение caps и
неверный профиль отклоняются без SCPI. Подмена readback вызывает fault и попытку
OFF. Отказ связи при моделируемом ON запрещает дальнейшие команды старого сеанса,
включая повторный ON и автоматическое восстановление. Состояние выхода при этом
может остаться ON. Новый сеанс также не разрешает ON без явного применения
валидного профиля; применение профиля сначала выключает выходы. Существующие
регрессии проверяют неполные/запоздалые ответы Serial/TCP.

На приборе: снимок исходных настроек; проверка исходного OFF и независимого режима;
профиль с разными уставками; 12 негативных вызовов без отправки SCPI;
проверка целостности профиля, emergency_off, финальные readbacks всех каналов,
таймеров, лимитов и режимов, чистая очередь ошибок и возврат панели через SYST:LOC.
Все команды проходят через диспетчер библиотеки и общий StageAdapter.

Физический обрыв USB при включённом выходе не входит в этот проход.
Реальное восстановление после обрыва связи этим проходом не квалифицируется.
Нельзя считать отсутствие связи доказательством OFF.

Карточка без доступа к приборам:

```sh
PYTHONPATH=src:tests/hardware python3 tools/hw_qualify.py preflight H12 --config config/bench.local.toml
```

Разрешение одного аппаратного прохода:

```text
CONFIRM H12 OFF_DIAGNOSTIC INDEPENDENT ALL_OFF LOAD=DISCONNECTED DMM=DISCONNECTED SCOPE=DISCONNECTED NO_JUMPERS RECALL=OFF
```

После прохода оператор независимо проверяет OFF и свободные клеммы:

```text
CONFIRM H12 CH1=OFF CH2=OFF CH3=OFF LOAD=OFF DISCONNECTED NO_JUMPERS
```

## Результат H12 — 2026-10-27

**PASS (HW OBSERVED; только OFF-сценарий).** Все 12 негативных вызовов
отклонены без SCPI. Итоговые V/I уставки, лимиты, таймеры и Independent mode
прочитаны; CH1/CH2/CH3 и KEL103 OFF, ошибок прибора нет. Оператор подтвердил
OFF и физически свободные клеммы. 218 ответов `SYST:ERR?` — `0, "No error"`.

В одном прогоне `*IDN?` дважды сообщил разные firmware fields: `1.04-1.04` и
`1.04-0.01`. В меню прибора ранее прочитано Main `1.04` / Aux `0.01`; протокол
сохраняет оба ответа, причина расхождения не установлена. Потеря USB при
включённом выходе была проверена только симуляцией.
