# R4.5-B — безопасная аппаратная проверка наблюдения INST?/STEP

**СТАТУС: подготовлено, SIM TESTED; HW NOT_RUN.** До проверки исходного JSONL
никакой из новых ответов нельзя маркировать HW REVIEWED PASS.

## Две отдельно разрешаемые фазы

**1. INST OFF-only:** только Keithley 2231A, CH1/CH2/CH3 физически OFF,
все выходные клеммы пусты, нет соединительных перемычек, DUT, нагрузки и
соседнего владельца порта. Независимая топология и Recall OFF подтверждены
оператором. Runner читает `INST?` один раз и сравнивает с `INST:NSEL?`,
контролирует три выхода и топологию до и после. Никакой профиль не
применяется и уставки не изменяются. Разрешены только REM, выбор канала и
заключительный LOC. `SYST:ERR?` опрашивается после каждого разрешённого
запроса; это **потребляет** очередь SCPI-ошибок.

**2. STEP OFF-profile:** требует *второго* независимого подтверждения при
физически выключенных и свободных клеммах. Взята уже программно испытанная
конфигурация Independent R4.4-C: CH1 3.30 В / 0.150 А, CH2 и CH3 1.00 В /
0.100 А, с аппаратными лимитами 3.50/1.50/1.50 В. Это **запись цифровых
уставок**, не подача питания. Вся последовательность apply_profile() выполняется
через существующий драйвер и ограниченную allowlist. Только после проверки
OFF выполняются по одному `VOLT:STEP?` и `CURR:STEP?` **для CH1**. Реальный
формат `VOLT:STEP?` неоднозначен в руководстве: ответ `None`, ошибочный
числовой формат или timeout дают ABORTED, без повтора на неопределённом UART.
Для допустимого конечного числа результат фиксируется как наблюдение;
значения шага заранее не предполагаются, не записываются и не применяются.

Завершение профильной фазы: `emergency_off()`, подтверждённый readback OFF
для CH1/CH2/CH3, затем допустимый `SYST:LOC`, независимое подтверждение
оператора. Если связь неопределённа, автоматические команды на этот UART
не повторяются, реальный OFF проверяется человеком. Ошибка evidence не
может блокировать допустимый аварийный OFF; PASS при неполных доказательствах
запрещён.

## Инструкция, без аппаратного разрешения

```bash
python3 tools/r4_5_source_qualify.py --config config/bench.local.toml
```

Это сухой просмотр: **не открывает прибор**. Отдельные аппаратные режимы
`--execute` (только INST?) и `--execute --steps` (включая изменения OFF-уставок)
выполнять лишь после проверки настоящей схемы стенда и явного разрешения.
Ни один из них не должен включать источник питания.

## Запреты и границы доказательств

Не включать нагрузку, не подключать DUT, не применять кабели Series/Parallel,
не запускать OUTP 1, CHAN:OUTP 1, VOLT/CURR:STEP записи, UP/DOWN, TRIG,
*TRG, *RST, *CLS, *RCL, event-запросы или другие изменяющие состояние команды
вне OFF-профиля. Последний SYST:LOC отправляется без ответного readback.
Успешная проверка одной независимой точки CH1 не доказывает форму STEP-ответа
на других каналах, влияние шага на активном выходе, его сохранение или
поведение после изменения UP/DOWN.
