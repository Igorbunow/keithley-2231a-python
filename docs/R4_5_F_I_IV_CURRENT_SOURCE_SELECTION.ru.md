# R4.5-F-I — безопасный выбор источника тока для анализа ВАХ

**Статус: SOFTWARE ONLY. Никаких новых аппаратных включений.**

## Задача и границы

В R4.5-F-H отделены безопасность источника и метрологическая пригодность результата. Этот этап вводит единый, **переиспользуемый офлайн-контракт выбора** `tools/iv_current_source_policy.py` и применяет его к исходному 5-точечному R45FD в `tools/r4_5_1n4933_iv_current_select.py`. Параметр `--current-source` не является запросом на управление измерительными приборами; он выбирает только реально записанные **в том же проверенном опыте** данные.

Перед выбором обязательно перепроверяются исходный JSONL (SHA-256, целостность, provenance), физическая SCPI-трасса, режимы, пять точек, подтверждения OFF и сами численные поля. Повторно используется `audit_r4_5_1n4933_evidence.audit()` и `r4_5_1n4933_export.prepare_export()` — **нового парсера, второй реализации прибора или автоматической калибровки нет**.

## Контракт выбора

- `auto`: выбрать **один** наиболее подходящий реально доступный метод для **всех** точек одного run SHA-256; порядок диагностических методов: последовательный DMM DCI, прямое DCV на балласте / R, последовательная разность PSU DCV и DMM DCV на диоде / R. Этот приоритет **не** устанавливает метрологическую точность.
- `SEQUENTIAL_PSU_MINUS_DIODE_DCV_OVER_R`: доступен для исходной пяти-точечной прямой ВАХ R45FD. Это **расчётная диагностика**, не независимый амперметр.
- `DIRECT_BALLAST_DCV_OVER_R` и `DMM_SERIES_DCI`: имеются **только в других, одноточечных** опытах R45FE/R45FG. На пяти-точечном R45FD **отклоняются**, значения из других запусков не подставляются.
- `PSU_READBACK`: допускается как контрольная и защитная телеметрия, но **никогда как источник точной либо диагностической ВАХ**. Соответствующее поле сохраняется отдельно `psu_control_readback_ma` для сравнения.
- `--intent metrology`: **отклоняется**. Вся текущая точность тока `UNQUALIFIED`, калиброванная ВАХ не заявляется.

Входная таблица кандидатов проверяется на уникальность метода в каждой точке, последовательность индексов, единый SHA-256 исходного журнала, конечность измерений, отсутствие отрицательного тока и ложных заявлений о синхронности/калибровке. Автоматический выбор **не допускает перехода на другой метод по отдельным точкам**. При отсутствии запрошенного метода на хотя бы одной точке возникает отказ, без скрытого fallback. Все статусы аппаратной квалификации неизменны.

Это офлайн-расширение анализа, а не новая функциональность `src/` или DMM7510: данные о токе DMM7510 из будущих много-точечных измерений можно будет подключить после **нового независимого аппаратного аудита** соответствующего оригинального журнала. Одна реальная R45FG точка такой аудит для пяти точек не заменяет.

## Пример использования

```bash
EVENTS=reports/hardware/2026-10-30T153942.522961Z_R45FD_1N4933_forward_five_points/events.jsonl
HASH=bdb2859180a8aaadf13a0d6e76e46111dbdb0d2b606977b2dbc016e7a87fd56b

python3 tools/r4_5_1n4933_iv_current_select.py "$EVENTS" \
  --expected-sha256 "$HASH" --current-source auto

python3 tools/r4_5_1n4933_iv_current_select.py "$EVENTS" \
  --expected-sha256 "$HASH" --current-source auto \
  --output-dir /tmp/r45fi_1n4933_selected_current

# Должно завершиться отказом (в этом пяти-точечном опыте нет DMM DCI):
python3 tools/r4_5_1n4933_iv_current_select.py "$EVENTS" \
  --expected-sha256 "$HASH" --current-source DMM_SERIES_DCI
```

Первый запуск по умолчанию ничего не записывает. `--output-dir` создаёт только новый, ранее не существовавший каталог, через проверенный общий `r4_5_iv_export.export_files()`; перезапись существующего каталога или исходного JSONL запрещена.

## Выходные данные

- `points.csv` — пять измеренных U диода с выбранным расчётным током, явной меткой метода, отдельным контрольным PSU readback, SHA-256 оригинального run, временным разносом PSU/DMM, `UNQUALIFIED`.
- `segments.csv` — четыре последовательных **описательных** приращения, не доказанная динамическая характеристика и не поверка.
- `summary.json` — происхождение, способ выбора, неподтверждённая метрология, аппаратный статус `UNCHANGED` и прямой запрет межопытной подстановки / калибровочных поправок.

Серийные номера, адреса TCP/UART, тексты SCPI и сырой JSONL в экспорт не копируются. Для дальнейших прецизионных ВАХ нужна новая измерительная программа с **синхронизацией, заданным методом и независимой оценкой неопределённости**. R4.5-F-I не разрешает автоматически включать оборудование.
