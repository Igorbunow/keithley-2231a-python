# R4.5-A — безопасный обзор цифровых SCPI-регистров (без аппаратного запуска)

**Статус: SIM TESTED, HW NOT_RUN.** Результаты R4.4-C по измерению мощности
не подтверждают ни одну из трёх новых команд.

## Граница пакета

Разрешены только запросы `INST?` (символьное имя канала), `VOLT:STEP?` и
`CURR:STEP?` (наблюдение величины уже настроенного шага). Последние два
доступны только через активный профиль Independent и после проверки его
целостности. Для `INST?` профиль не требуется. Вспомогательные команды
аутентификации и Remote и выбор канала могут выполняться основной библиотекой.

Никакие команды `VOLT:STEP <x>`, `CURR:STEP <x>`, `UP/DOWN`, `TRIG`, `*TRG`,
`OUTP:ENAB`, `APPLy`, `*RST`, `*RCL` и иные изменяющие настройки команды
на данном этапе не разблокируются. Не допускать подключения DUT и силовых
испытаний как следствия простого программного PASS.

## Аппаратная неопределённость

По Reference Manual 077100401 (09.2014), §5:

- стр. 5-11: `INSTrument[:SELect]?` возвращает `CH1/CH2/CH3`;
- стр. 5-25: `CURRent:STEP?` возвращает величину шага тока;
- стр. 5-27: `VOLTage:STEP?` присутствует в синтаксисе и примере, но в
  таблице «Returns» указано **None**. Реальная форма ответа неизвестна.

Поэтому для будущей аппаратной проверки требуется отдельная OFF-only
процедура с ручным подтверждением всех CH1/CH2/CH3 OFF, сверкой топологии,
фиксированным allowlist и полным JSONL. Профиль должен применяться только
при гарантированно отключённых клеммах, причём сам его apply может менять
цифровые уставки и состояние Front Panel/Remote. Такой runner в R4.5-A
не добавлен. Реальные значения регистров и реакция конкретной прошивки
остаются **неподтверждёнными**.

При синтаксической ошибке/тайм-ауте не повторять запрос на том же UART,
не утверждать OFF без отдельного readback. Требуется независимый осмотр
SCPI-trace перед повышением статуса до HW REVIEWED PASS.
