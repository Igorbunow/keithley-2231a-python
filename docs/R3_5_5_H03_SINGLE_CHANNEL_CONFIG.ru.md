# R3.5.5 — одноканальный H03: конфигурация и OFFLINE preflight

**Статус:** подготовка / CONFIG ONLY. Никакая команда с `--single-channel-cvcc`
не может открыть порты или включить выходы. Полная H03 осталась без изменений.
Это ещё **не** аппаратная квалификация CV/CC и не разрешение на `--execute`.

## Единственный источник настроек

В файл `config/bench.local.toml` добавляется раздел
`[qualification.h03_single_cvcc]`; образец с точными полями и исходными
проверенными значениями приведён в комментариях `config/bench.example.toml`.
Не заменяйте локальный bench на пример и не копируйте секретные/реальные
сведения в репозиторий. Смена одного байта TOML меняет SHA256 общего
подтверждения. Раздел обязателен целиком: скрытых дефолтов нет.

Программные потолки нельзя увеличить конфигурацией: только CH1; по
каналам V-cap ≤4.00/4.05/4.10 В, I-cap ≤0.300/0.400/0.500 А;
рабочие CH1 U≤4.00 В, I(CV)≤0.300 А, I(CC)≤0.250 А,
максимум 1.20 Вт в профиле. CR разрешены только 40 Ω (CV) и 12 Ω (CC).
Проверяются физические соотношения CV/CC и достаточность мощности.

## Безопасная проверка

```bash
python3 tools/hw_qualify.py preflight H03 --single-channel-cvcc --config config/bench.local.toml
python3 tools/hw_qualify.py run H03 --single-channel-cvcc --config config/bench.local.toml --dry-run
```

Обе команды не открывают соединений. Попытка `run ... --execute`
останавливается **до входа в общий Connection Gate**, независимо от TTY.
Штатный `H03` без нового флага по-прежнему означает **все три канала**;
ни `--start-channel 1`, ни статус исторического H03 не ограничивают его одним.

## Следующий инкремент (ещё не реализован)

Отдельный runner должен принимать только валидированную конфигурацию,
использовать общий USB/проверку идентичности/операторские подтверждения,
только `CHAN:OUTP 1` для CH1, оставить CH2/CH3 физически свободными;
обе точки с OFF→CR setup→INPUT ON→CH1 ON→CV/CC/readback→CH1 OFF→INPUT OFF;
не пытаться писать после неопределённости канала связи. Каждая точка
закрывается собственным подтверждением OFF. Требуется отдельный
операторский допуск и аудитор отправленных SCPI-команд.

**Запрещено** запускать полный H03 в качестве временной замены.
