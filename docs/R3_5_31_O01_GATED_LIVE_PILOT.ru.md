# R3.5.31 — O01 bounded live pilot

После успешного R3.5.30 offline-аудита включён отдельный интерактивный
O01 аппаратный вход с дополнительным opt-in `--allow-o01-on`.

- Подтверждение BENCH и согласованной схемы **до открытия портов**;
  USB VID:PID проверяется системой; DMM подключается только к FRONT DCV.
- DMM конфигурируется при отсоединённых щупах; физический CONNECT gate
  проверяется до CH1 ON; NO LOAD, NO DUT, NO JUMPERS.
- 0.5/1.0/1.5 V, I-limit 40 mA, только CH1 ON; однократный sweep,
  измерение DMM строго после показания PSU, host clocks, числовой CSV.
- Неопределённый UART запрещает дальнейший обмен; ошибка DMM при рабочем
  PSU приводит к аварийному OFF с readback по живому PSU.
- OFF и отключение DMM подтверждаются оператором отдельным финальным token;
  ни один PASS не означает точной временной синхронизации двух приборов.
- O01 остаётся HW NOT_RUN пока не появятся реальные архивы; результаты
  не повышаются в HW VERIFIED без review сырых SCPI и CSV.

Перед запуском прочитать `docs/O01_STAGE_PREFLIGHT.ru.md`.
